# Security

Found a security problem in Fettle: in the Windows app, the website, or share links? Please tell us privately instead of opening a public issue:

- write to [security@fettle.page](mailto:security@fettle.page), in English or Italian, or
- use **Report a vulnerability** on this repository's Security tab.

Say what you found, how to reproduce it, and which version you used (Fettle's About panel shows it). You'll get a reply, and a fix goes into the next release. Your name goes in its notes if you'd like.

Only the latest release gets fixes: https://github.com/fettle-page/fettle/releases/latest

A share link being misused (someone shared another person's report, say): [abuse@fettle.page](mailto:abuse@fettle.page).
